# Movie Application

A Movie Application developed using Node.js, Express, MongoDB, HTML, CSS and JavaScript.

## Features

- Add movies
- View movies
- Edit movies
- Delete movies
- Search movies by title
- Filter movies by genre

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## How to Run

1. Install Node.js and MongoDB.
2. Open the project folder in VS Code.
3. Start MongoDB.
4. Run:

```bash
node server.js
